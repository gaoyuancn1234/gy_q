## 调研结果

> 注：这套思路和 `trading_framework/` 已经在跑的系统（CLAUDE.md 里记录的实盘）高度重合——两个论文指的应该是 QuantaAlpha (2602.07085) 和 FactorMiner (2602.14670)，都已经在 `feature/qlib-integration` 分支落地。写这份文档前建议先明确：ezio 是要另起一套，还是给现有系统补文档/查漏补缺。

### 一、A股散户交易的硬约束

| 项目 | 规则 | 对策略设计的影响 |
|---|---|---|
| T+1 | 当日买入次日才能卖出（T+0 仅个别 ETF 可行） | 日内高频/T+0 策略在个股上做不了，只能做日频以上的持仓型策略 |
| 最小交易单位 | 1 手 = 100 股起（卖出可零股一次性卖清） | 10万分散买 12-20 只，平均每只约 5000~8000 元。股价超过 50~80 元的股票，100 股就要吃掉 5000~8000+ 元仓位，股价几百元的（消费龙头、次新股等）基本没法等权配进去——选股池要么避开高价股，要么用非等权重方案 |
| 涨跌停 | 主板/中小板 ±10%，ST/*ST ±5%，科创板/创业板 ±20%，北交所 ±30% | 若股票池覆盖科创板/创业板，回测要考虑涨跌停无法成交的滑点情形 |
| 印花税 | 卖出单边收 0.05%（2023.8.28 起从 0.1% 下调） | 只在卖出时计，买入不收 |
| 佣金 | 券商自定，一般万 2.5~万 3（0.025%~0.03%），双向收取，每笔最低 5 元 | 10万本金、单笔几千元的仓位，最低 5 元佣金占比不可忽略——频繁调仓（如每周）要把最低佣金计入回测成本，否则回测收益会虚高 |
| 过户费 | 沪市 0.001%（双向），深市已取消 | 金额很小，可忽略 |
| 红利税 | 持股 <1个月 20%，1个月~1年 10%，>1年 免征（差别化） | 若策略持仓周期短（如5天一调仓），分红部分要按 20% 计提，但通常调仓策略持仓期短、分红占收益比例也低，影响有限 |
| 资本利得税 | 个人股票买卖价差收益不征个人所得税 | 好消息，不用像美股那样考虑资本利得税拖累 |

**结论**：日频/周频调仓型策略在成本结构上是合理的（T+1 决定不能做日内，交易成本决定不能太高频）；但"10万分散买 12-20 只"要在选股池阶段就排除掉股价过高的标的，否则等权重分配根本买不了整手。

### 二、适合散户的日/周频 ML/DL 策略调研

现有系统采用的是：LightGBM（alpha158 因子）+ 15日相对强度轮动/ML 信号 + TopK 12-20 等权 + 每5个交易日调仓，这个设置本身就是学术界和量化圈对"散户友好、鲁棒性优先"策略的典型选择，原因：

1. **模型选择**：LightGBM/树模型在中低频截面因子预测上表现稳健、可解释、训练快，优于 LSTM/Transformer 这类深度模型在小样本（A股历史相对短、非平稳）上容易过拟合的问题——这也是为什么 QuantaAlpha/FactorMiner 走的是"LLM 生成因子表达式 + 传统 ML 排序模型"路线，而不是端到端深度学习。
2. **调仓频率**：5日/周频是业界常见选择——太高频（日频以下）交易成本和滑点侵蚀收益；太低频（月频以上）信号衰减、错过轮动机会。

### 三、回测周期怎么定

项目自己的 `papers/quantaalpha/README.md` 里已有直接结论：

- 旧单次训练因子：Sharpe **-22%**（样本外劣化）
- 新 rolling 因子：Sharpe **+17%**（样本外提升）
- 结论：**因子必须在 rolling walk-forward 下评估才能反映真实质量**

即"回测周期不能太长"这个直觉是对的，但更准确的说法是：不是单纯缩短回测总长度，而是不能用单次静态切分（train/test 一刀切），而要用滚动窗口（walk-forward）：比如现有系统用的"9窗口 walk-forward"，每个窗口 3个月验证+3个月重训（D3v3r），这样能避免"在牛市训练、熊市验证"这种单一时段偏差，也能及时发现像"Window 8 崩溃"（验证集某季度 IC 反转）这种鲁棒性问题。

### 四、整体思路

```
资金 10万 → A股现券，T+1、最小100股
  │
  ├─ 选股池：剔除股价过高标的（100股超过总资金 5~8% 的），避免等权配置买不起整手
  │
  ├─ 因子挖掘（每日）：QuantaAlpha 演化循环 + FactorMiner 假说生成/筛选漏斗
  │     → 每日渐进式产生假说 → 验证 → IC/ICIR 评估 → rolling 回测对比
  │
  ├─ 信号生成：LightGBM (alpha158 + 挖掘出的新因子) → TopK 12-20 等权（或按可买手数调整）
  │
  ├─ 调仓：每 5 个交易日（日频/周频之间），兼顾信号新鲜度和交易成本
  │
  ├─ 回测：9窗口 walk-forward（非单次切分），每窗口 3个月训练验证周期，季度重训
  │
  └─ 每日运维：盘中监控（止损/异动）+ 收盘复盘 + 影子交易验证新因子（不影响实盘，平行验证后再 promote）
```
