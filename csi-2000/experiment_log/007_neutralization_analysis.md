# 实验 007: 行业/市值中性化分析

## 目的

分析当前最佳策略 (D_expand_3v_3r + LightGBM + alpha158_val, Sharpe=2.202) 的收益来源：
- **Sharpe 2.2 里有多少是真正的选股 alpha，有多少只是行业/市值暴露的"马甲"？**

## 方法

### 数据
- 预测结果: `results/rolling/predictions/D_expand_3v_3r_alpha158_val_LightGBM.pkl`
- 行业分类: BaoStock `query_stock_industry()` 申万一级行业 (42个行业, 300只股票, 覆盖率100%)
- 市值数据: Qlib `$total_mv`
- 价格数据: Qlib `$open`, `$close`

### 分析内容

1. **持仓暴露分析**: 行业 HHI、行业偏离度、市值暴露
2. **Brinson 收益归因**: R_total = R_allocation + R_selection + R_interaction
3. **中性化对比回测**:
   - 方式 A: 行业内 z-score 中性化
   - 方式 B: 行业 + 市值 OLS 回归残差中性化

## 脚本

```bash
python -m factor_lab.run_neutralization_analysis
```

## 结果

### 暴露分析
- 行业 HHI: **0.5082** (高集中度, >0.15 阈值)
- 行业偏离度 (L1): **1.1875** (极高偏离)
- 单行业最大占比: **100%** (J66 货币金融服务, 即银行/保险)
- 组合平均 60.8% 权重在货币金融服务, 基准仅 8.3%
- 市值偏好: 组合平均市值 **4218 亿** vs 全市场 **1908 亿** → **显著大市值偏好**
- log(市值)偏差: **+0.5693**

### Brinson 归因
- 超额收益: 2.15%
- 各分项正负抵消严重 (配置 +8.6%, 选股 -33.0%, 交互 +26.5%)
- 绝对值占比近似均等 (配置 33.3%, 选股 33.7%, 交互 33.0%)
- 归因残差: 0.000000 (精确)

### 中性化回测对比

| 配置 | Sharpe | 收益 | 最大回撤 |
|------|--------|------|----------|
| 原始信号 | **2.202** | 117.48% | -12.55% |
| 行业中性化 | **1.504** | 80.45% | -23.29% |
| 行业+市值中性化 | **1.055** | 48.29% | -18.51% |

### 收益来源拆解 (基于中性化回测)

| 来源 | Sharpe 贡献占比 |
|------|----------------|
| 行业暴露 | ~32% |
| 市值暴露 | ~20% |
| **纯选股 alpha** | **~48%** |

## 关键发现

1. **策略极度集中在银行/保险行业** (J66 货币金融服务占组合 60.8%, 基准仅 8.3%)
   - 这解释了低回撤: 银行股波动小
   - 但风格切换风险极高

2. **存在真实选股 alpha, 但不占主导**
   - 行业+市值中性化后 Sharpe 仍有 1.055, 说明模型确实学到了选股信号
   - 但约 52% 的 Sharpe 来自行业/市值暴露

3. **大市值偏好**
   - 组合平均市值 4218 亿 vs 全市场 1908 亿
   - 非小市值偏好 (NEG_LOG_MV 因子方向相反)
   - 大市值 = 低波动 = 高 Sharpe 的部分原因

4. **中性化后最大回撤反而增大**
   - 行业中性化后 MDD 从 -12.55% 恶化到 -23.29%
   - 说明银行集中持仓实际上提供了"下行保护"

## 结论

存在真实选股 alpha (Sharpe 1.055), 但行业/市值暴露贡献显著 (~52%)。策略兼具行业择时和选股能力, 风格切换时需警惕回撤。

**建议**: 可考虑增加行业约束 (如单行业上限 30%) 以提高稳健性。
